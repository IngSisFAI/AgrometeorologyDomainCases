# Reuse-Oriented Big Data System
This is a set of _domain cases_ developed using our big data methodology focudes on **reuse**.

**Domain**: Agrometeorology

**Objetive**: To analyze the influence of weather variables on late spring frosts in Alto Valle of Río Negro and Neuquén (Patagonia, Argentina).

**Development**: Two domain cases: *Domain case 1 - Villa Regina* and *Domain case 2 - Guerrico*

Repository of assets (folders): 
* **OriginalDatasets**: Source datasets from both cases
* **PreparedData**: Prepared data for both cases
* **NotebookCodes**: Jupyter notebook codes in python for preparation and analisys activities. 
* **Results**: Some of the results obtained from the analysis.

Documentation: 
* **Bibliography**: Bachelor's thesis and articles describing the analysis.
